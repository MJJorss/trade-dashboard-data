# MJ Investment Index — retired 28 Nov 2026

The MJ Investment Index was retired and replaced by the Small-strong basket (the website's Investment tab).
These are its last published files, kept for reference; nothing on the website reads them.

- `investment_index.json` — holdings and watchlist at the last rebalance
- `investment_equity_history.json` — its equity curve
- `investment_closed_trades.json` — its closed trades

The code (`investment_index.py`) and its state (`investment_state.json`) stay in the trade-alerts repo; see its README.
